# Décisions d'architecture (ADR)

Une décision structurante = un fichier `NNNN-titre-court.md`, numéroté à la suite, jamais
modifié après acceptation (on le remplace par une nouvelle ADR qui le « remplace »).

Modèle :

```markdown
# NNNN — Titre

- Statut : proposée | acceptée | remplacée par NNNN
- Date : AAAA-MM-JJ
- Auteur : rôle de l'agent (ou Mathis)

## Contexte
## Décision
## Options écartées
## Conséquences
```
