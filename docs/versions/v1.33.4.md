# v1.33.4 — Plantes côté eau au paludarium

Cycle 312 (sprint 45), issue #847.

## Ce qui change

- Le paludarium est désormais planté côté eau dès son ouverture : deux plantes à tige (l'une
  sur la pente immergée, l'autre sur le fond plat), une touffe et une plante flottante.
- Les plantes posées sur la pente suivent le sol ; aucune ne pousse côté terre.
- Un couple de tritons bien nourri peut donc pondre dans leurs feuilles immergées sans avoir
  à importer une sauvegarde plantée.

## Limites connues

- Le décor du paludarium reste fixe : on ne peut pas encore y ajouter, déplacer ou retirer
  des plantes (ADR 0185).
- Une sauvegarde du paludarium créée avant cette version garde son décor vide.
