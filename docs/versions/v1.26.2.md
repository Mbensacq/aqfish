# v1.26.2 — Assainissement : tests de mutation des feuilles mortes, de la pièce et du siphon

Cycle 261, issue #699 (lot 13/13, dernier, du chantier d'assainissement #686, sprint 38).

## Ce qui change

- Rien à l'écran : les feuilles mortes du bassin, les détails de la pièce (plinthes,
  moulures, porte, applique) et le siphon se comportent exactement comme avant (167/167
  captures identiques au pixel près à la version précédente).
- En coulisses, de nouveaux tests tuent les mutants survivants des trois fichiers les plus
  faibles de la mutation hebdomadaire : feuilles mortes 64,9 % → 92,4 %, détails de la pièce
  72 % → 93,1 %, siphon 72,1 % → 97,4 % (bornes basses, mesurées sur le seul fichier de test
  du module).
- Une garde de code mort est retirée du calcul des feuilles mortes (une feuille pas encore
  née était déjà écartée par son âge négatif).

## Limites connues

- Les mutants restants sont équivalents (détaillés dans la PR) ; les scores exacts seront
  ceux de la prochaine mutation hebdomadaire, avec toute la suite de tests.
