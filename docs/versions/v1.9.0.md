Première version du sprint 21 (cycle 140) : étagère d'animalerie à trois niveaux dans la pièce.

## Ce qui change

- **Nouveau meuble « Étagère d'animalerie »** dans le catalogue « Bacs et meubles » : une étagère métallique à trois tablettes (10, 76 et 142 cm), sur laquelle on pose jusqu'à trois bacs l'un au-dessus de l'autre.
- Ajouter un bac sur l'étagère remplit les niveaux du bas vers le haut ; la liste des bacs indique le niveau (« posé sur Étagère d'animalerie 1, niveau 2 »).
- Un bac trop haut pour un niveau est refusé (« Le bac est trop haut pour cette place. ») ; l'étagère ne peut pas être retirée tant qu'un de ses niveaux porte un bac.
- Les sauvegardes existantes se chargent à l'identique ; une pièce avec étagère garde le niveau de chaque bac.
- La rangée de boutons « Bacs et meubles » passe à la ligne au lieu de déborder du panneau.

## Limites connues

- Pas de choix explicite du niveau dans le panneau : la pose suit l'ordre du bas vers le haut.
- Un bac posé n'est pas encore sélectionnable (limite existante, ADR 0075).
- La vue de trois quarts reste centrée sur le bac principal : l'étagère s'y voit mal ; la vue libre la montre en entier.
