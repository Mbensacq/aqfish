# v1.34.5 — Relevé des âges plus léger

Cycle 320 (sprint 46), dette technique : issue #868.

## Ce qui change

- Rien à l'écran : les 189 captures sont identiques à celles de la version précédente.
- Sous le capot : le relevé des âges de chaque espèce (rafraîchi quatre fois par seconde)
  ne construit plus aucun objet tant que les nombres de jours affichés ne changent pas.
- L'écart de quelques pixels observé sur le bandeau de l'horloge dans une série de captures
  est expliqué (anticrénelage des coins arrondis, pas les polices) et la règle de comparaison
  est consignée pour l'équipe.

## Limites connues

- Les coins arrondis du bandeau peuvent encore varier d'un niveau sous forte charge ; c'est
  du bruit de capture, sans effet visible.
