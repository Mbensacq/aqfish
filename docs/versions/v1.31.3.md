# v1.31.3 — Refuge gradué des alevins

Cycle 297 (sprint 43, fonctionnalité), issue #823 (tranche 2 de #731).

## Ce qui change

- Les plantes protègent les alevins selon leur masse : une touffe dense ou une plante bien
  poussée cache tous les alevins proches, une petite touffe ou une plante taillée n'en cache
  qu'une partie. Sans plante, les alevins n'ont aucun refuge.
- Un bac très planté garde donc plus d'alevins qu'un bac peu planté.
- Le bilan du bac (tableau de bord) signale « Alevins sans refuge suffisant » quand moins de la
  moitié des alevins sont à l'abri, avec le compte et l'action conseillée.
- Les anciennes sauvegardes se relisent sans changement.

## Limites connues

- Les plantes flottantes (lentille d'eau, salvinia) ne sont pas encore proposées : issue #824.
- Pas encore de jeunes crevettes ni de refuge pour elles (avec #732).
- Le seuil de couverture pleine (0,03 m²) est une approximation de jeu (ADR 0176).
- Les captures des bacs à alevins changent légèrement (positions des alevins).
