# v1.29.3 — Données d'écologie du paludarium

Cycle 283 (sprint 41), issue #786 : dernière tranche des données d'écologie (#727).

## Ce qui change

- Rien à l'écran : les trois amphibiens du paludarium (axolotl, sonneur oriental, triton à
  ventre de feu) reçoivent à leur tour leurs données d'écologie (densité, dureté tolérée,
  nourriture, proies et prédateurs, comportements).
- Les 29 espèces du jeu ont désormais toutes leurs données : toute nouvelle espèce devra les
  fournir.
- Pour les amphibiens, la densité se compte sur l'eau du milieu, berge déduite (le sonneur
  vit avec environ un quart de berge sèche).

## Limites connues

- Ces données ne sont pas encore utilisées par la simulation ni affichées dans le wiki.
- Plusieurs valeurs des amphibiens (part d'eau de l'axolotl et du triton, densité) sont des
  approximations de jeu, signalées comme telles.
