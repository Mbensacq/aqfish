Cinquième version du sprint 14 (cycle 95) : aides pour débutant (#240).

## Ce qui change

- **Guide du débutant** : une fenêtre en cinq étapes (installer le bac, faire mûrir l'eau, choisir les espèces, nourrir, entretenir), chacune avec l'endroit où le faire dans le jeu.
- Le guide **s'ouvre une seule fois, à la première visite** ; on le retrouve ensuite dans le **Wiki**, liste des guides, entrée « Guide du débutant ».
- **« Pourquoi ? »** : sous le détail d'une alerte (ammoniaque, nitrites, température, pH, faim…), un bouton ouvre le guide sur l'explication liée, déjà dépliée.
- Huit explications courtes : cycle de l'azote, température, pH, eau trouble, acclimatation, nourriture, santé, cohabitation. Chacune indique sa source ou la mention « Simplification de jeu ».
- Le guide se lit au clavier (Tab reste dans la fenêtre, Échap la ferme et rend la main là où on était) et au lecteur d'écran ; il tient sur téléphone.

## Limites connues

- Pas de bouton « Pourquoi ? » sur chaque jauge du cadre du haut, pour ne pas l'élargir (ADR 0072) : les explications des jauges sont dans le guide et sous les alertes.
- Les sources affichées renvoient à la documentation du projet (`docs/SOINS.md`), pas directement aux publications.
- Ce jeu n'est pas un avis vétérinaire.
