# v1.35.4 — Anniversaires et doyen du bac

Cycle 326 (sprint 47), fonctionnalité : issue #877.

## Ce qui change

- Le journal du bac note les anniversaires : chaque année de jeu révolue d'un animal entre au
  journal (famille « Santé »), par exemple « Anniversaire : Néon, 2 ans (3 animaux) ». Les
  animaux d'une même espèce qui atteignent le même âge partagent une seule ligne.
- Le bilan du bac, une fois déplié, désigne le doyen : l'animal vivant le plus âgé, avec son
  espèce et son âge (« Doyen du bac : Corydora, 4 ans et 152 jours. »). La ligne reste lisible
  sur un téléphone (390 px de large).
- Un anniversaire n'est jamais noté deux fois, même après le rechargement d'une sauvegarde.

## Limites connues

- Quand le temps avance de plusieurs années d'un coup, seuls les trois derniers anniversaires
  de chaque animal sont notés.
- Les anniversaires passés avant le chargement d'une sauvegarde ne sont pas rattrapés.
- Les animaux ne portent pas de nom : le doyen est désigné par son espèce.
