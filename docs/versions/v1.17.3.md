# v1.17.3 — Les alevins grandissent

## Ce qui change à l'écran

- **Trois étapes de croissance visibles.** Les alevins (guppys nés, corydoras éclos) passent
  par trois tailles bien distinctes, nouveau-né, juvénile puis subadulte (environ la moitié,
  les deux tiers puis les quatre cinquièmes de l'adulte), avant de devenir adultes.
- **Ils se colorent en grandissant.** Un nouveau-né est pâle, presque couleur de sable ; il
  prend peu à peu les couleurs de son espèce et les a toutes une fois adulte.
- **Reproduction à l'âge adulte** seulement : un alevin ne se reproduit pas, il le peut dès
  qu'il est adulte.
- La fiche du guppy décrit ces étapes. Le bac par défaut et ses captures sont inchangés.

## Limites connues

- L'âge adulte (20 minutes simulées) est une approximation de jeu : dans la réalité, le
  guppy devient adulte vers deux à trois mois.
- Vue de dessus, un alevin pâle sur le sable se voit à peine (camouflage voulu) ; la vue de
  face montre mieux les trois tailles.
