# v1.20.0 — Outillage : tests de bout en bout sur les nouveaux serveurs

Première version du sprint 32 (cycle 217, correctif d'outillage).

## Ce qui change à l'écran

- Rien : l'apparence et le comportement sont identiques à v1.19.5 sous les 5 angles
  (135 captures identiques octet pour octet à la série du cycle 216).
- En coulisses : l'outil de tests de bout en bout passe en version 1.63.0, la seule à
  reconnaître les nouveaux serveurs d'intégration continue (Ubuntu 26.04). Les versions
  peuvent de nouveau être vérifiées et publiées.

## Limites connues

- Celles de v1.19.5 : le tuyau n'est pas encore dessiné pendant le siphon, le niveau d'eau ne
  baisse pas au siphon, le filtre et la taille n'ont pas encore leur geste dans la séance.
