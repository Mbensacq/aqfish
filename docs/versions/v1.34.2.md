# v1.34.2 — Mue des crevettes et exuvies

Cycle 317 (sprint 46), fonctionnalité : issue #859.

## Ce qui change

- Les crevettes cerises muent : un jeune plus souvent qu'un adulte (environ tous les trois
  jours de jeu pour un adulte).
- Chaque mue laisse au sable une petite exuvie claire, dans l'axe de la crevette ; elle pâlit
  à mi-vie puis se dissout après trois jours de jeu (32 exuvies au plus dans le bac).
- Juste après sa mue, la crevette se cache : aucun poisson ne peut la manger pendant ce temps
  (approximation de jeu).
- Le journal note chaque mue par une ligne neutre « Mue » ; les exuvies sont conservées dans
  la sauvegarde.

## Limites connues

- La crevette cachée continue de nager normalement : seule la prédation l'épargne.
- Une colonie nombreuse écrit souvent « Mue » au journal.
