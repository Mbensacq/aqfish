# v1.19.3 — Suites de revue : raclette et mortalité

Quatrième version du sprint 31 (cycle 213, dette).

## Ce qui change à l'écran

- Rien de visible : rendu identique à v1.19.2 sous les 5 angles.
- **Raclette des vitres** : les points d'un même mouvement de souris ou de doigt sont
  traités ensemble ; un glissé rapide efface les mêmes taches, avec une seule sauvegarde par
  mouvement.
- **Sauvegardes** : un fichier où un corps porte l'identifiant d'un animal vivant est
  refusé à l'import, avec un message qui le dit.
- **Mortalité** : chaque animal n'est tiré au sort qu'une fois par pas de simulation (mêmes
  décès qu'avant, calcul plus léger).

## Limites connues

- Celles de v1.19.2 : seule l'étape des vitres a son geste ; la raclette retire une tache
  entière d'un coup.
