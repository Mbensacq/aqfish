# v1.23.4 — Assainissement : types du monde à part, plus aucun cycle d'import

Cycle 241, issue #687 (lot 1/13 du chantier d'assainissement #686, sprint 35).

## Ce qui change

- Rien à l'écran : l'aquarium, ses animaux et ses réglages se comportent exactement comme avant
  (captures identiques au pixel près, empreintes de simulation inchangées).
- En coulisses, les types de l'état du monde vivent dans un module à part, l'application des
  effectifs d'espèces et l'échelle de santé ont leur propre module, et le code ne contient plus
  aucun cycle d'import à l'exécution : la base est plus simple à faire évoluer.

## Limites connues

- Il reste des cycles d'imports de types dans `sim/` (plus grande composante : 22 modules au lieu
  de 60), traités par les lots suivants du chantier.
