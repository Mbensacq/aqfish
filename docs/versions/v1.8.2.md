Troisième version du sprint 20 (cycle 135) : l'aquarium respecte la demande « réduire les mouvements ».

## Ce qui change

- **Nouvelle section « Accessibilité » dans les réglages**, avec la case **« Réduire les mouvements »**. Elle est cochée d'office si le système le demande (`prefers-reduced-motion`), et le choix fait dans les réglages est mémorisé dans le navigateur.
- Option active :
  - les **changements de vue** (dessus, face, côté, 3/4…) se font d'un coup, sans glissement de caméra ;
  - l'**eau** (caustiques, reflet de surface, nénuphars) bouge quatre fois plus lentement, les **plantes** ondulent moins ;
  - la **pluie** tombe plus lentement ;
  - en **mode immersif**, la parallaxe liée à l'inclinaison de l'appareil est coupée.
- Les poissons, les soins et la simulation sont strictement identiques avec ou sans l'option ; sans l'option, l'affichage ne change pas.

## Limites connues

- La légère secousse des poissons quand on tapote la vitre relève de la simulation : elle n'est pas atténuée (voir l'ADR 0098).
- Activer ou couper l'option pendant que l'eau ou la pluie bougent provoque un petit saut de ces animations.
