# v1.15.5 — Bilan : toutes les espèces hors plage de dureté

## Ce qui change à l'écran

- Dans le bilan du bac (tableau de bord), le point « Dureté de l’eau mal adaptée » compte
  désormais toutes les espèces dont la plage de dureté ne convient pas, et les nomme avec leur
  plage (par exemple « 2 espèces hors plage : néons (1 – 12 °dGH) ; mollys (15 – 30 °dGH) »).
  Avec une seule espèce concernée, le texte est inchangé.
- Le reste de l'application est identique à la v1.15.4 (nettoyage interne du bilan, sans
  changement d'apparence).

## Limites connues

- Un bac surpeuplé affiche toujours « Aucune alerte » dans le bandeau alors que le bilan signale
  la densité (à trancher avec l'épopée alertes, #522 point 3).
