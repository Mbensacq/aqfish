# v1.28.5 — Nettoyage du tableau de bord

Cycle 278 (sprint 40, cycle de dette), issues #780 et #770.

- Aucun changement visible : les icônes pixel du tableau de bord de l'eau (chevrons et
  niveaux des jauges) passent par le composant d'icône commun, au lieu de quatre copies.
- Code mort retiré (calcul de contraste du tableau de bord estompé) et commentaires remis
  à jour.

  version précédente est trouvée et documentée : le nouveau plan du bouton « Pharmacie ».

## Limites connues

  restent (invisibles à l'œil) : ils accompagnent le correctif de la version 1.28.4.
