Sixième version du sprint 14 (cycle 96, dette) : suites du guide du débutant et du wiki (#302, #296).

## Ce qui change

- **Sources lisibles** : les fiches, le wiki, le guide de soins et le guide du débutant n'affichent plus de chemin de fichier du projet ; on lit « Source : documentation du projet (FishBase) », avec la publication citée.
- **Wiki, comparaison avec le bac** : la valeur du bac s'affiche au dixième, comme dans le cadre du haut (« Bac : 24,0 °C », « Bac : 7,0 »).
- **Couleurs de l'avis** (dans la plage, limite, hors plage) : exactement celles de la jauge pH.
- **Nitrates** : l'explication précise que, dans le jeu, seul un changement d'eau partiel les fait baisser, alors que dans un vrai bac les plantes en absorbent aussi une partie.

## Limites connues

- Une source qui cite plusieurs documents répète « documentation du projet » (un peu verbeux).
- La simulation ne modélise pas l'absorption des nitrates par les plantes.
- Ce jeu n'est pas un avis vétérinaire.
