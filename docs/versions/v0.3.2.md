Troisième version du sprint 3 (cycle 16, épopée v0.3 « Le décor ») : des plantes poussent dans le sable du bac tropical et ondulent doucement.

## Ce qui change

- **Plantes** : six plantes en voxels rejoignent les rochers, sous deux formes : de longues tiges à feuilles alternées vers le fond, des touffes basses devant (#49).
- **Ondulation** : les plantes ondulent lentement (environ 5 s par balancement), chacune à son rythme ; seule la partie haute bouge, la racine reste plantée dans le sable.
- **Les poissons contournent les tiges** sans les traverser ; le feuillage, lui, reste traversable.
- **Contour pixel art** : chaque plante est cernée du même liseré sombre d'un pixel que les rochers, y compris pendant l'ondulation.

## Limites connues

- Vue de dessus, les plantes forment des taches vertes au contour bruité, peu lisibles (même défaut que les rochers, suivi dans #59).
- Les trajectoires du monde par défaut changent par rapport à v0.3.1 (nouveaux obstacles, même graine).
