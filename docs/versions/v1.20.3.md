# v1.20.3 — Intégration continue plus fiable

Quatrième version du sprint 32 (cycle 219, issue #600). Version technique : rien ne change à
l'écran.

## Ce qui change

- Les tests de bout en bout de l'intégration continue sont mieux répartis entre les 7 machines :
  les deux fichiers les plus longs (cadrage des panneaux, panneau de contrôle) sont scindés et
  les durées de référence remesurées. Chaque part dure désormais 21 à 36 min (auparavant 16 à
  46 min, avec des annulations au plafond de 45 min qui bloquaient les fusions).
- Un garde-fou vérifie que la répartition estimée reste sous 30 min par part.
- Même nombre de tests qu'avant, contenu inchangé. Apparence identique à v1.20.2 sous les
  5 angles.

## Limites connues

- La marge reste mince sur une machine lente ; une 8e part est proposée en #632 (décision de
  Mathis, zone protégée).
