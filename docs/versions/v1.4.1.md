Deuxième version du sprint 16 (cycle 106, v1.4 « La pièce complète ») : aqfish peut servir de fond d'écran animé, par exemple avec Wallpaper Engine.

## Ce qui change

- Nouvelle vue « fond d'écran » : en ajoutant `?fond=1` à l'adresse, seul l'aquarium s'affiche, sans aucun panneau, bouton ni message.
- La caméra se balance lentement d'elle-même autour du bac (aller-retour en 90 s autour de la vue trois-quarts) ; la souris ne la fait pas dévier.
- La scène affichée est, dans l'ordre : le fichier `aqfish-fond.json` placé à côté de la page (un export fait depuis l'application), sinon votre sauvegarde locale, sinon la scène par défaut. Un fichier illisible est ignoré.
- Vue légère : 30 images par seconde par défaut, réglables de 15 à 60 avec `fps=` ; l'animation s'arrête quand la page est masquée et reprend sans à-coup.
- La vue fond d'écran n'écrit jamais dans votre sauvegarde.
- La commande `npm run paquet-fond` prépare un dossier prêt à importer dans Wallpaper Engine (configuration d'exemple et image d'aperçu comprises) ; guide pas à pas dans `docs/FOND-ECRAN.md`.
- L'application habituelle ne change pas à l'écran.

## Limites connues

- **Non essayé dans Wallpaper Engine** : si Wallpaper Engine ouvre le dossier en `file://` sans autoriser l'accès aux fichiers voisins, la page peut ne pas démarrer. À vérifier par Mathis (voir le guide).
- Le dossier n'est pas encore joint aux versions publiées : il faut le produire soi-même avec `npm run paquet-fond` (suite prévue dans #330).
- Sans fichier `aqfish-fond.json` (site en ligne), la console du navigateur signale une erreur 404 avant le repli sur la sauvegarde ; sans conséquence à l'écran.
- Pas encore de réglages propres à Wallpaper Engine (propriétés utilisateur), ni de son.
