- Rien dans le bac : les 167 captures sont identiques à la version précédente.
- Import d'une sauvegarde refusée : un corps invalide est désormais signalé comme tel
  (« corps 0 : … », « dead doit être une liste ») au lieu d'être confondu avec un poisson
  vivant.

  marche (plus de tampon global) ; le contrôle « un seul bac au jardin » est justifié et
  couvert par un test (deux bassins dans une même sauvegarde).
