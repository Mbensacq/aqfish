# v1.23.5 — Assainissement : le pas de simulation découpé en étapes nommées

Cycle 242, issue #688 (lot 2/13 du chantier d'assainissement #686, sprint 35).

## Ce qui change

- Rien à l'écran : l'aquarium, ses animaux et ses réglages se comportent exactement comme avant
  (empreintes de simulation identiques au bit près, captures identiques).
- En coulisses, le pas de simulation, jusque-là une seule longue fonction, est découpé en
  quatorze étapes courtes et nommées (horloge, nage, repas, eau, algues, plantes, maladies,
  santé, population), appelées toujours dans le même ordre, documenté dans l'architecture.
- Dix nouveaux scénarios de caractérisation (mode décor, distributeur, courant, alevins, œufs,
  maladies, mortalité…) protègent désormais ce pas contre toute régression.

## Limites connues

- Le module `sim/world.ts` reste long (près de 1 500 lignes) : les lots suivants du chantier
  continuent de le découper.
- La capture « fiche d'espèce » sur téléphone varie parfois de quelques pixels d'une série à
  l'autre (animation), sans lien avec cette version.
