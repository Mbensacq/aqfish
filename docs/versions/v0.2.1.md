Deuxième version du sprint 2 (cycle 8) : les néons nagent en banc.

## Ce qui change

- **Banc de néons** : les néons se rapprochent, s'alignent et gardent leurs distances (séparation, alignement, cohésion). Après quelques secondes, ils forment un ou deux groupes qui nagent dans la même direction (#27).
- Les néons ne se chevauchent plus : un espacement minimal (≈ 2 cm) est maintenu entre eux.
- Le bac compte désormais **12 néons** par défaut (8 auparavant).
- Même graine, même image : le comportement de banc reste déterministe.

## Limites connues

- Le banc n'anticipe pas les parois : près d'un bord, chaque néon l'évite seul, ce qui peut scinder le groupe (évitement des parois prévu à l'issue suivante).
- Vus en trois-quarts, les néons restent petits et le banc occupe peu de place à l'écran.
