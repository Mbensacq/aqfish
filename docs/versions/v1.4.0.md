Première version du sprint 16 (cycle 105, v1.4 « La pièce complète ») : le retour du mode décor vers le mode soins signale désormais les animaux qui ne conviennent pas au bac.

## Ce qui change

- En repassant un bac du mode décor au mode soins, la confirmation liste les animaux qui ne conviennent pas, avec leur effectif et la raison en une ligne : autre milieu (« vit dans « Récif » »), eau hors de la température tolérée, bac trop petit pour l'espèce, groupe trop petit, ou espèce déconseillée avec une autre déjà présente.
- Deux choix : **Tout retirer** enlève exactement les animaux listés ; **Tout garder** les conserve avec les avertissements habituels. « Annuler » laisse le bac en mode décor.
- Animaux d'un autre milieu gardés en mode soins : une ligne d'avertissement les signale désormais dans le panneau « Réglages ».
- Sans animal inadapté, la confirmation reste celle d'avant (« Revenir au mode soins »), sans liste.
- Dans les deux cas, l'eau, la faim et la santé reprennent où elles en étaient.
- La confirmation tient à l'écran à 1280 px comme sur téléphone (390 px) : la liste défile si elle est longue et les boutons passent à la ligne.

## Limites connues

- Le retrait se fait en bloc : pas de choix espèce par espèce.
- Aucun environnement actuel ne contient deux espèces déconseillées ensemble : la raison « compatibilité » n'apparaîtra qu'avec une espèce à venir.
- Pas de transfert automatique des animaux retirés vers un autre bac ; pas de mode décor pour le jardin.
- Sur ordinateur, la confirmation recouvre le centre du bac le temps du choix.
- Ce jeu n'est pas un avis vétérinaire.
