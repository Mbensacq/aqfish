# v1.27.3 — Réglages sur téléphone

Cycle 269, issue #722 (tranche 3).

## Ce qui change

- Sur téléphone (moins de 640 px de large), les réglages ne prennent plus tout l'écran : un
  panneau monte du bas sur environ les trois quarts de la hauteur, le haut de la page reste
  visible ; toucher le fond assombri le ferme.
- Le panneau montre d'abord la recherche puis la liste des catégories, chacune avec sa valeur
  du moment (« 24 animaux », « Eau à 24 °C », « Pause, 12:00, heure figée », « Coupés »…).
- Toucher une catégorie ouvre son contenu dans le même panneau ; « ‹ Retour » ramène à la
  liste.
- Boutons d'au moins 44 px pour le doigt (catégories, retour, fermer, recherche).
- Sur un écran plus large, rien ne change ; le bac lui-même ne change pas.

## Limites connues

- Les produits sont encore dans « Eau et matériel » et « Pluie » n'est pas encore dans
  « Affichage » : suivi dans #762.
- La recherche reste un champ réservé, le filtrage arrive avec le lot suivant.
