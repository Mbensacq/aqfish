# v1.21.5 — Entretien : garde de comparaison du relevé

Sixième version du sprint 33 (cycle 229, dette, issue #520).

## Ce qui change

- Rien à l'écran : version de consolidation.
- Un nouveau test vérifie que la comparaison du relevé d'entretien (échéances, tâches échues,
  journal) tient compte de chacun de ses champs, y compris ceux qui seraient ajoutés plus tard.
  Le tableau de bord ne pourra donc pas garder un relevé périmé parce qu'un champ a été oublié
  dans la comparaison.

## Limites connues

- Au téléphone, le rappel d'entretien reste une icône sans libellé quand rien n'est échu ; la
  capture `alerte-animaux.png` n'a pas été régénérée depuis c176. Ces deux points sont repris
  dans une issue de dette séparée.
