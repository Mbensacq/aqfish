Quatrième version du sprint 21 (cycle 143) : partager un aquarium par lien.

## Ce qui change

- **Bouton « Partager ce bac »** dans la section « Sauvegarde » du panneau : il produit un lien contenant le bac affiché (population, décor, réglages), compressé dans l'adresse elle-même. Le lien est copié dans le presse-papiers quand le navigateur l'accepte et reste affiché dans un champ à copier à la main.
- **Ouvrir un lien partagé** affiche un bandeau « Importer cet aquarium » / « Ignorer » : rien n'est remplacé sans confirmation. Le bandeau indique l'environnement, le nombre d'animaux et le nombre de bacs actuels qui seront remplacés, et invite à exporter d'abord.
- Un lien abîmé, d'une version future ou au contenu invalide (espèce inconnue, trop d'animaux, données hors bornes) est refusé avec un message lisible.
- Un bac trop riche pour tenir dans un lien (plus de 32 000 caractères) : le message propose de partager le fichier avec « Exporter ».
- Aucun serveur : le contenu reste dans le fragment de l'adresse (après `#`), jamais transmis au site.

## Limites connues

- Accepter un lien remplace toute la pièce par le bac reçu ; l'ajouter à côté des bacs existants n'est pas encore possible.
- Le nom personnalisé du bac n'est pas transmis.
- Sur téléphone, le bandeau de refus d'un lien recouvre la barre du haut tant qu'on ne le ferme pas.
- Les messages de refus distinguent mal certains cas de liens mal formés (préfixe de version incorrect).
